# Comparative Analysis of CNN-Based and Transformer-Based Object Detectors
## for Real-Time FFF 3D Printing Defect Detection

Final Project — Deep Learning Course (Dr. Bahaghighat)

## Project Phases
1. Literature Review
2. Dataset Preparation
3. Baseline Reproduction (YOLOv8)
4. RT-DETR Implementation
5. DINO Detector Implementation
6. Quantitative Performance Comparison
7. Robustness Evaluation
8. Explainability Analysis
9. Statistical Analysis
10. Scientific Discussion

## Structure
- `configs/` — YAML configs (dataset, per-model, shared hyperparameters)
- `data/` — raw, processed, annotations, corrupted (robustness) images
- `notebooks/` — one notebook per phase
- `src/` — reusable code (data, models, explainability, stats)
- `results/` — outputs per model + comparison tables + statistical tests
- `report/` — final report and figures
